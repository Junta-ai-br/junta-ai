## Objetivo

Ajustar a navegação principal da Junta.ai para melhorar a organização da interface e preparar a evolução do frontend.

---

## Alterações realizadas

### Header

Foram realizadas melhorias no componente de navegação principal (`Header`), incluindo ajustes de layout e estrutura para acomodar a evolução das funcionalidades da aplicação.

### Organização visual

- Refinamento do posicionamento dos elementos do Header.
- Ajustes na hierarquia visual da navegação.
- Melhor preparação da interface para futuras páginas e funcionalidades.

### Estilização

Atualização dos estilos relacionados ao Header para manter consistência com o Design System da Junta.ai.

Arquivos envolvidos:

```
frontend-v2/src/components/navigation/Header/Header.css
frontend-v2/src/styles/themes/theme.css
```

---

## Resultado

O Header passou a possuir uma estrutura mais consistente e preparada para a evolução da aplicação, mantendo alinhamento com o Design System do projeto.
