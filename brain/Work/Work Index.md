# Work

This directory contains active work including tasks, meetings and drafts.

Documents here may eventually evolve into permanent knowledge stored in the Knowledge directory.

---

## Categories

### Tasks

Executable work items. Each task should reference the Feature or Decision that originated it.

Tasks are finite, actionable and measurable.

### Meetings

Discussions and their outcomes.

Meetings should summarize participants, context, decisions and action items.

Important information from meetings should migrate to the appropriate canonical document in Knowledge.

### Drafts

Documents in progress that have not yet been promoted to permanent knowledge.

---

## Lifecycle

Documents in Work naturally progress toward Knowledge as they mature.

```text
Work → Knowledge → Archive
```
