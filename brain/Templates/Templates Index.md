# Templates

This directory contains the official document templates for the Knowledge Operating System.

Every new document should be created from the appropriate template.

Templates must never be recreated by inference. If no suitable template exists, report the gap and request approval before introducing a new one.

---

## Available Templates

### Knowledge Entities

- [[Vision]] — Long-term project direction
- [[Strategy]] — How the vision will be achieved
- [[Research]] — Information collected before decisions
- [[Decision]] — Important project decisions
- [[ADR]] — Architecture Decision Record (Decision variant)
- [[Feature]] — Product capabilities

### Work Entities

- [[Task]] — Executable work items
- [[Meeting]] — Discussion summaries and outcomes

### Reference Entities

- [[Reference]] — Stable information for consultation

---

## Template Selection

Before creating a new document:

1. Identify the Knowledge Entity.
2. Locate the corresponding template above.
3. Use the canonical template.
4. Populate only the information required for that document.
