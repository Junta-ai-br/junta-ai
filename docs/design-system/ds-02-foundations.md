# Foundations

Os Foundations representam a base visual do Design System do Junta.ai.

Eles definem os elementos fundamentais que dão identidade ao produto e garantem consistência em todas as interfaces.

Em vez de criar decisões visuais para cada tela, utilizamos um conjunto de padrões compartilhados por toda a aplicação.

---

# Objetivo

Os Foundations existem para reduzir inconsistências e facilitar o desenvolvimento.

Quando todos os componentes utilizam a mesma base visual, a experiência se torna mais previsível para o usuário e mais simples para a equipe desenvolver e manter.

---

# O que faz parte dos Foundations

Os Foundations do Junta.ai são compostos pelos seguintes elementos:

### Colors

Define como utilizamos as cores da aplicação, incluindo identidade visual, cores neutras e estados semânticos.

---

### Typography

Define famílias tipográficas, escalas, pesos e regras de utilização dos textos.

---

### Spacing

Define os espaçamentos utilizados entre componentes, seções e elementos da interface.

---

### Radius

Define os arredondamentos utilizados em componentes e superfícies.

---

### Shadows

Define os níveis de profundidade utilizados para destacar elementos da interface.

---

### Motion

Define princípios de animação, transições e microinterações do produto.

---

### Icons

Define como a iconografia deve ser utilizada dentro da aplicação.

---

# Como utilizar os Foundations

Antes de criar um novo componente ou interface, consulte os Foundations.

Eles representam as decisões oficiais do Design System e devem ser reutilizados sempre que possível.

Evite criar novos padrões quando já existir uma solução documentada.

---

# Evolução

Os Foundations evoluem junto com o produto.

Novos tokens, ajustes de escala ou melhorias visuais podem acontecer ao longo do desenvolvimento, desde que mantenham a consistência do Design System e sejam documentados.

---

# Relação com os componentes

Os Foundations definem a base.

Os componentes utilizam essa base para construir a interface.

Em outras palavras:

- Foundations respondem **quais decisões visuais seguimos**.
- Components mostram **como aplicamos essas decisões na prática**.
