# Typography

A tipografia do Junta.ai foi definida para tornar a leitura confortável e criar uma hierarquia visual clara em toda a aplicação.

Cada estilo possui uma função específica e deve ser utilizado de forma consistente em todas as interfaces.

---

# Objetivo

A tipografia existe para organizar a informação.

Mais do que escolher fontes bonitas, buscamos facilitar a leitura, destacar o que realmente importa e criar uma experiência visual consistente.

---

# Famílias tipográficas

O Design System utiliza três famílias de fontes.

## Heading

Utilizada em títulos e elementos de destaque.

Características:

- forte presença visual;
- personalidade da marca;
- utilizada apenas para títulos.

Fonte utilizada:

**Satoshi**

---

## Body

Utilizada em textos, componentes e elementos da interface.

Características:

- excelente legibilidade;
- leitura confortável;
- aparência neutra.

Fonte utilizada:

**Inter**

---

## Monospace

Utilizada apenas para conteúdos técnicos.

Exemplos:

- blocos de código;
- comandos;
- identificadores.

Fonte utilizada:

**JetBrains Mono**

---

# Hierarquia tipográfica

A aplicação utiliza uma escala consistente para organizar o conteúdo.

Da maior para a menor:

- Hero
- Display
- Heading
- Title
- Subtitle
- Body
- Small
- Caption

Cada nível possui um papel específico e deve ser utilizado conforme sua importância na interface.

---

# Pesos tipográficos

Os pesos ajudam a reforçar a hierarquia visual.

Utilizamos:

- Light (300)
- Regular (400)
- Medium (500)
- Semibold (600)
- Bold (700)

Em geral:

- títulos utilizam Semibold ou Bold;
- textos utilizam Regular;
- botões e elementos interativos utilizam Medium.

---

# Line Height

O espaçamento entre linhas varia de acordo com o tipo de conteúdo.

Títulos utilizam alturas menores para reforçar a proximidade entre palavras.

Textos utilizam alturas maiores para facilitar a leitura.

Sempre utilize os valores definidos pelo Design System.

---

# Letter Spacing

O espaçamento entre caracteres é utilizado apenas para pequenos ajustes de leitura e identidade visual.

Os títulos possuem um leve espaçamento negativo para criar uma aparência mais compacta.

Os textos utilizam espaçamento neutro.

---

# Como utilizar

Ao desenvolver uma interface:

- utilize Heading para títulos;
- utilize Body para textos;
- mantenha a hierarquia visual consistente;
- evite criar novos tamanhos de fonte sem necessidade;
- utilize sempre os tokens definidos pelo Design System.

---

# Boas práticas

✔ Utilize a escala tipográfica existente.

✔ Utilize as famílias definidas pelo Design System.

✔ Respeite a hierarquia dos títulos.

✔ Priorize a legibilidade.

✔ Utilize os tokens em vez de valores fixos.

---

# Onde encontrar os tokens

Os valores oficiais da tipografia estão definidos nos arquivos de tokens do Design System.

A documentação explica como utilizar esses elementos.

Os arquivos de tokens representam a fonte oficial dos valores implementados.
