# Visão Geral

O Design System do Junta.ai é o conjunto de princípios, padrões e componentes que orientam o desenvolvimento da interface do produto.

Seu objetivo é garantir que todas as telas ofereçam uma experiência consistente, facilitando tanto o desenvolvimento quanto a evolução da aplicação ao longo do tempo.

Mais do que um conjunto de componentes, ele representa a linguagem visual do Junta.ai.

---

# Por que ele existe?

À medida que um produto cresce, diferentes pessoas passam a desenvolver novas funcionalidades.

Sem um padrão compartilhado, pequenas diferenças começam a surgir:

- botões com estilos diferentes;
- espaçamentos inconsistentes;
- cores utilizadas de maneiras distintas;
- componentes duplicados;
- comportamentos diferentes para situações semelhantes.

O Design System existe para evitar esse problema.

Ele define uma base comum para toda a equipe, permitindo que novas interfaces sejam construídas de forma consistente.

---

# Nosso objetivo

O Design System foi criado para servir como um guia para quem desenvolve interfaces no Junta.ai.

Seu papel é reduzir dúvidas durante o desenvolvimento e permitir que a equipe concentre seus esforços na resolução de problemas, e não na criação de novos padrões visuais a cada funcionalidade.

Sempre que possível, novas interfaces devem reutilizar componentes e decisões já existentes.

---

# Como utilizamos o Design System

O Design System é utilizado durante todo o desenvolvimento do frontend.

Ele orienta decisões relacionadas a:

- identidade visual;
- componentes;
- tipografia;
- cores;
- espaçamentos;
- animações;
- estados de interação;
- acessibilidade;
- comportamento da interface.

Quando uma nova necessidade surgir, a equipe deve verificar primeiro se ela pode ser atendida pelos padrões já existentes antes de criar uma nova solução.

---

# Estrutura da documentação

A documentação do Design System está organizada em duas partes principais.

## Foundations

Documenta os fundamentos visuais que dão identidade ao produto.

Inclui tópicos como:

- cores;
- tipografia;
- espaçamentos;
- bordas;
- sombras;
- movimento;
- iconografia.

Esses elementos representam as decisões visuais utilizadas por toda a aplicação.

---

## Components

Documenta os componentes reutilizáveis do sistema.

Cada componente possui sua própria documentação contendo:

- objetivo;
- quando utilizar;
- estrutura;
- variantes;
- estados;
- boas práticas.

Sempre que um novo componente fizer parte oficialmente do Junta.ai, sua documentação deverá ser criada ou atualizada.

---

# Como este documento influencia o desenvolvimento

Antes de criar um novo componente ou uma nova interface, a equipe deve se perguntar:

- Já existe uma solução para este problema?
- Posso reutilizar um componente existente?
- Estou seguindo os padrões definidos pelo Design System?
- Esta solução mantém a consistência da aplicação?

Essas perguntas ajudam a manter uma experiência unificada para todos os usuários.

---

# Filosofia

O Design System do Junta.ai segue alguns princípios simples.

- Consistência antes de personalização.
- Clareza antes de decoração.
- Reutilização antes de duplicação.
- Simplicidade antes de complexidade.
- A experiência do usuário sempre vem primeiro.

Esses princípios orientam todas as decisões relacionadas à interface do produto.
