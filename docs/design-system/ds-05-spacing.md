# Spacing

O espaçamento organiza a interface e influencia diretamente a percepção de qualidade do produto.

Mais do que separar elementos, ele cria ritmo, facilita a leitura e ajuda o usuário a compreender a relação entre diferentes informações.

---

# Objetivo

O Design System utiliza uma escala consistente de espaçamentos para manter equilíbrio visual em toda a aplicação.

Sempre que possível, componentes e layouts devem reutilizar essa escala em vez de definir valores específicos para cada situação.

---

# Onde utilizamos espaçamentos

Os espaçamentos são utilizados em diferentes níveis da interface.

Exemplos:

- entre componentes;
- entre seções;
- dentro de cartões;
- entre elementos de formulários;
- entre textos;
- entre ícones e textos.

Todos esses casos devem seguir a mesma lógica definida pelo Design System.

---

# Consistência

Elementos semelhantes devem possuir espaçamentos semelhantes.

Quando dois componentes exercem funções parecidas, o usuário espera encontrar o mesmo padrão visual entre eles.

A consistência reduz a sensação de desorganização e torna a interface mais previsível.

---

# Espaçamento como hierarquia

O espaçamento também comunica importância.

Em geral:

- elementos relacionados ficam próximos;
- grupos diferentes possuem maior separação;
- seções utilizam espaçamentos maiores do que componentes internos.

Essa organização ajuda o usuário a interpretar a interface sem necessidade de explicações.

---

# Como utilizar

Ao construir uma interface:

- utilize os tokens de espaçamento definidos pelo Design System;
- mantenha uma escala consistente;
- reutilize padrões existentes;
- evite definir valores arbitrários.

Sempre que houver dúvida, prefira reutilizar um espaçamento já existente em vez de criar um novo.

---

# Boas práticas

✔ Utilize sempre os tokens do Design System.

✔ Mantenha o mesmo padrão entre componentes semelhantes.

✔ Utilize o espaçamento para organizar informações.

✔ Evite criar exceções sem necessidade.

✔ Priorize consistência em toda a aplicação.

---

# Onde encontrar os tokens

Os valores oficiais de espaçamento estão definidos nos arquivos de tokens do Design System.

A documentação explica quando utilizar esses espaçamentos.

Os tokens representam a fonte oficial para implementação.
