# Radius

O Radius define o arredondamento utilizado em componentes e superfícies da interface.

Mais do que um detalhe visual, ele contribui para a identidade do produto e influencia a forma como os usuários percebem a experiência.

---

# Objetivo

O Design System utiliza uma escala consistente de bordas arredondadas para criar uma interface moderna, organizada e acolhedora.

Todos os componentes devem reutilizar essa escala, evitando valores diferentes para situações semelhantes.

---

# Onde utilizamos Radius

Os arredondamentos estão presentes em diversos elementos da interface.

Exemplos:

- botões;
- cartões;
- campos de formulário;
- modais;
- menus;
- badges;
- avatares;
- áreas de destaque.

Cada componente utiliza o nível de radius mais adequado ao seu contexto.

---

# Consistência

Componentes com funções semelhantes devem compartilhar o mesmo padrão de arredondamento.

Essa consistência fortalece a identidade visual do produto e reduz a sensação de interfaces desconectadas.

Sempre que possível, reutilize os valores já definidos pelo Design System.

---

# Radius também comunica

O arredondamento ajuda a transmitir personalidade.

No Junta.ai, utilizamos cantos arredondados para criar uma experiência mais leve, amigável e acessível, sem perder a sensação de precisão necessária para um produto financeiro.

O objetivo é encontrar um equilíbrio entre confiança e proximidade.

---

# Como utilizar

Ao desenvolver um componente:

- utilize sempre os tokens de radius definidos pelo Design System;
- mantenha consistência entre componentes semelhantes;
- reutilize padrões existentes;
- evite criar novos valores sem necessidade.

Quando houver dúvida, prefira utilizar um radius já existente em vez de definir um novo.

---

# Boas práticas

✔ Utilize sempre os tokens do Design System.

✔ Mantenha o mesmo padrão entre componentes semelhantes.

✔ Utilize o radius para reforçar a identidade visual.

✔ Evite criar exceções sem necessidade.

✔ Priorize consistência em toda a aplicação.

---

# Onde encontrar os tokens

Os valores oficiais de radius estão definidos nos arquivos de tokens do Design System.

A documentação explica quando utilizar cada nível de arredondamento.

Os tokens representam a fonte oficial para implementação.
