# Público-alvo

O Junta.ai foi desenvolvido para pessoas que desejam organizar melhor sua vida financeira de forma simples, prática e acessível.

Nosso foco está em usuários que procuram orientação, organização e acompanhamento, sem precisar dominar conceitos financeiros ou utilizar ferramentas complexas.

A experiência deve ser intuitiva o suficiente para que qualquer pessoa consiga começar a utilizá-la por meio de uma conversa.

---

# Para quem estamos construindo

Hoje, o Junta.ai foi pensado principalmente para pessoas que:

- desejam organizar melhor receitas e despesas;
- têm dificuldade em manter planilhas ou aplicativos tradicionais;
- buscam criar hábitos financeiros mais saudáveis;
- preferem uma experiência simples e conversacional;
- valorizam orientações claras para tomar melhores decisões financeiras.

Esses usuários não procuram apenas registrar informações. Eles procuram compreender melhor sua relação com o dinheiro.

---

# Para quem o produto não foi pensado

Neste momento, o Junta.ai não tem como objetivo atender usuários que procuram:

- plataformas para investimentos;
- análises financeiras avançadas;
- ferramentas de gestão empresarial;
- controles contábeis;
- recursos voltados para profissionais do mercado financeiro.

Esses cenários podem ser explorados futuramente, mas não fazem parte do escopo atual do produto.

---

# O que nossos usuários esperam

Ao utilizar o Junta.ai, esperamos que o usuário encontre uma experiência que seja:

- simples de utilizar;
- acolhedora;
- intuitiva;
- transparente;
- confiável;
- útil no dia a dia.

Mais do que adicionar funcionalidades, buscamos reduzir o esforço necessário para organizar as finanças pessoais.

---

# Como este documento influencia o desenvolvimento

Sempre que uma nova funcionalidade for proposta, a equipe deve se perguntar:

- Essa funcionalidade resolve um problema do nosso público?
- Ela torna a experiência mais simples?
- Ela conversa com a proposta do produto?
- Ela continua adequada ao perfil de usuário que queremos atender?

Essas perguntas ajudam a manter o desenvolvimento alinhado com os objetivos do Junta.ai.
