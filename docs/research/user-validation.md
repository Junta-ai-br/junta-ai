# User Validation

## Objetivo

Registrar os testes realizados com usuários para verificar se as principais hipóteses do Junta.ai correspondem a necessidades e comportamentos reais.

Esta documentação deve permanecer objetiva. O objetivo é registrar aprendizados que possam alterar, confirmar ou priorizar decisões de desenvolvimento.

## Métodos possíveis

Conforme a etapa do projeto, podem ser utilizados:

- entrevistas;
- questionários;
- testes de usabilidade;
- comparação de fluxos;
- experimentos simples;
- observação de uso do protótipo ou MVP.

O método deve ser escolhido de acordo com a pergunta que precisa ser respondida.

## Princípio

A pesquisa não termina quando o desenvolvimento começa.

O objetivo é manter um ciclo simples:

**Pesquisar → formular hipótese → desenvolver → testar → aprender → ajustar.**

Os resultados podem confirmar ou modificar decisões existentes em `docs/product/`.
